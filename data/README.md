# Data

This project analyzes NYC 311 service requests for the 2025 calendar year.

The final analytical dataset contains 3,655,040 service requests and was prepared from the NYC OpenData 311 Service Requests dataset.

The project also uses:

- NYC geographic boundary data
- 2024 ACS 5-year socioeconomic data
- Census TIGER/Line geographic data

The full processed dataset is not included in this repository because of its large file size.

The analysis notebooks document the data recovery, cleaning, validation, geospatial processing, socioeconomic analysis, and Power BI preparation steps.

For reproducibility, the original source data can be obtained from NYC OpenData and the U.S. Census Bureau.
